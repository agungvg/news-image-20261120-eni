THE WORLD — a newspaper front page that sums up Friday 20 November 2026's world news in one image. Russian missiles hitting three Kyiv bridges leads, with 33 stories from 6 regions and a day-in-numbers box, drawn from scratch with Pillow. Stories verified from 20 November 2026 reporting: the Kyiv bridge barrage, Cyclone Akvan's landfall, Anthropic's record $81.3bn IPO, the AI sell-off, COP31's final day, the Trump–Xi–Putin declaration, the ICJ's Myanmar genocide ruling, and the UK–EU youth mobility deal.

## Run it

```sh
python3 draw.py
```

That writes `entry.png` (1024×1024, deterministic — two runs write byte-identical PNGs). `python3 main.py` writes the same image to `/output/entry.png` instead. No network, no clock, no randomness.
